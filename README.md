This project demonstrates a controlled AI prompting technique where the model is restricted to answer only from a given reference text. It is designed to reduce hallucination and improve answer reliability.

🎯 Objective

Ensure accurate and verifiable answers
Eliminate AI hallucinations
Provide traceable responses with citations
Simulate real-world QA systems used in industry

🧠 Use Cases

Document-based QA systems
AI evaluation & benchmarking
Academic tools
Legal/compliance assistants
Retrieval-Augmented Generation (RAG)

⚙️ How to Use

Provide a reference text with paragraph numbers
Ask a question based on the text
AI will:
Answer strictly from the text
Include paragraph citation
Return "Information is Not Found" if absent
